# Stock Trading Platform

A complete graphical Java application simulating a basic stock trading environment.

## Features

- **Real-Time Simulation**: View available stocks and their current prices.
- **Interactive Transactions**: Buy and sell stocks using a graphical user interface.
- **Portfolio Tracker**: Monitor owned shares, average buy prices, current values, and overall profits/losses.
- **Performance Summary**: Clear breakdown of total investments, valuation, and percentage gains/losses.
- **Transaction Logs**: Log of all past purchases and sales.
- **Auto-Save & Load**: Automatically saves transaction history and portfolio state to local files when exiting, and loads them at startup.

## Technologies Used

- **Java SE** (Java 17 or higher)
- **Java Swing** for GUI layout

## How to Run

1. Compile the Java files:
   ```cmd
   javac *.java
   ```
2. Run the application:
   ```cmd
   java Main
   ```
